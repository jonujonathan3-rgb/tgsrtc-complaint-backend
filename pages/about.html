About This Project

A web-based complaint management prototype designed to demonstrate how passengers could submit and track public transport complaints.

TGSRTC Complaint Portal

This project is a student-developed web application prototype created for learning and demonstration. It provides a simple interface where users can submit a complaint and receive a complaint ID.

Users can then use that complaint ID to view the complaint information and its current prototype status.

Key Features

📝

File Complaint

Submit passenger, journey and complaint information through a structured form.

🔎

Track Complaint

Use a generated complaint ID to view the complaint details and status.

📱

Responsive Design

The interface is designed to work across desktop, tablet and mobile screens.

🚌

Complaint Categories

Supports categories such as bus issues, staff complaints, fare issues and delays.

🔐

Simple Prototype

The current version stores demonstration data locally in the browser.

🚀

Future Backend

The project can later be connected to FastAPI and SQLite for persistent storage.

How It Works

1

Submit

Enter the required complaint and journey information and submit the form.

2

Track

A unique complaint ID is generated and can be used to track the submitted complaint.

3

Manage

A future backend and administrator dashboard can be used to manage complaint resolution.

Technologies Used

The current frontend prototype is built using standard web technologies. Backend integration can be added in the next development phase.

HTML5 CSS3 JavaScript LocalStorage FastAPI SQLite
